# SaborLocal app Pedro

O **Sabor Local** é um projeto acadêmico de desenvolvimento de um aplicativo de delivery criado do zero com o uso de tecnologias No/Low-code. O objetivo do projeto é centralizar pedidos, facilitar a experiência do cliente e apoiar a gestão do restaurante em uma solução moderna, prática e escalável.

O aplicativo foi desenvolvido com foco em organização, automação e integração entre diferentes ferramentas, demonstrando a construção de uma solução completa para pedidos, pagamentos e processos internos.

## Tecnologias utilizadas
- FlutterFlow
- Flutter
- Dart
- Xano
- Asaas
- n8n
- Telegram Bot
- Figma
- Trello
- Miro

## Objetivo do projeto
Criar uma solução digital para delivery que una aplicativo, automação e gestão administrativa em um único ecossistema.
